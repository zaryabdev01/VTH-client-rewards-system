# VTH Thank You Spin – Design Prototype

Clickable Next.js prototype for client design & UX sign-off. All data is sample content held in the browser (no backend).

```
npm install
npm run dev        # http://localhost:3000
```

Use the **Prototype guide** button (bottom-right) to jump between screens and copy demo codes.

| Demo code | Shows |
|---|---|
| VTH-7K2M-9QXA | Valid code -> wheel -> reward reveal |
| VTH-EXPD-4821 | Expired state |
| VTH-USED-0000 | Already-used state |
| anything else | Invalid state (5 failures -> rate-limit state) |

Screens: customer landing + wheel + reveal, rules & odds, staff login (Admin / Standard role), dashboard, codes & history (generate, copy, send, cancel, mark fulfilled), reward settings (admin edit / standard read-only), email templates (desktop/mobile preview).
